IMPOR DATABASE db_tk_final KE phpMyAdmin (dipecah jadi 10 file)

Sebelum mulai:
1. Di phpMyAdmin buat database baru, misalnya db_tk_final, collation utf8mb4_0900_ai_ci (MySQL 8.0).
2. Klik nama database itu di panel kiri, lalu pilih tab Import.
3. Impor file SATU PER SATU, urut dari 01 sampai 09. Jangan dibalik.
   Pakai tab Import (bukan tab SQL), karena file procedure, function, dan trigger memakai DELIMITER.
   Setelah tiap file muncul "Import has been successfully finished", lanjut ke file berikut.

Urutan:
 01_struktur_tabel.sql      30 tabel (belum ada index dan foreign key)
 02a_data.sql               data tabel pertama sampai kedua belas
 02b_data.sql               data tabel terakhir (wali)
 03_index_primary_key.sql   primary key dan index
 04_auto_increment.sql      AUTO_INCREMENT
 05_foreign_key.sql         foreign key
 06_function.sql            14 function
 07_procedure.sql           17 stored procedure
 08_view.sql                22 view
 09_trigger.sql             34 trigger (sengaja terakhir supaya tidak aktif saat data dimasukkan)

Catatan:
- Isi dan jumlah objek sama dengan file asli db_tk_final: 856 baris data, 83 perintah ALTER, 14 function, 17 procedure, 22 view, 34 trigger.
- Bagian DEFINER=`root`@`localhost` sudah dibuang supaya bisa diimpor di komputer teman yang akun MySQL-nya bukan root.
- Jika muncul error "log_bin_trust_function_creators" saat file 06, 07, atau 09, jalankan di tab SQL:
      SET GLOBAL log_bin_trust_function_creators = 1;
  lalu impor ulang file yang gagal (butuh akun root).
- Jika satu file gagal di tengah, hapus semua tabel di database lalu ulangi dari 01. Jangan impor ulang sebagian.
- Skrip pecahan ini belum dijalankan di server MySQL oleh penyusunnya; hasilnya diperiksa dengan membandingkan jumlah objek dengan file asli.
